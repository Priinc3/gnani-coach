# Phone check — 10 minutes

Open **https://gnani-coach.vercel.app** in Chrome on your phone.

1. The page loads with the Speaking Coach title. If not, send me a screenshot and the time.
2. Tap the browser menu → **Add to Home screen**. An icon appears. If not, send me the menu screenshot.
3. Open the installed icon. It fills the screen without browser bars. If not, send me a screenshot.
4. Create an account with your email and a password of 10+ characters. You land signed in. If not, send me the screen and the time (never the password).
5. Start a call, allow the microphone when Chrome asks. The coach greets you. If not, send me the exact message and a screenshot.
6. Say one short sentence and stop. The coach answers out loud within a few seconds. If not, send me the time and a screenshot.
7. Start speaking while the coach is talking. The coach audio stops and the coach listens. If not, send me the time.
8. Tap End. The call ends cleanly and a summary appears. If not, send me a screenshot.
9. Open History. Your call is listed; another account's call is not. If not, send me a screenshot.
10. Deny the microphone once, then allow it on retry. The call starts after you allow it. If not, send me the exact text.
11. Toggle airplane mode for 5 seconds during a call. A plain "connection" message appears, not a frozen screen. If not, send me the time and a screenshot.
12. The APK download is **not available yet** (GitHub Actions is blocked). Use the home-screen app above for now. If you want the APK, tell me after GitHub billing is fixed.
13. If anything looks wrong, send me: a screenshot, the local time, and what you tapped. **Never send a password, a key, or a full page of private text.**
