## Deliverables (only what the goal needs)
1. **`/ws/call`** (`conversation/router.py` keeps `router`, the path, and `origin_allowed` before `accept()`). Implements `call-transport.md` for real: first message must be a valid `start` (size ≤ 16 KiB, validated against the envelope schema), guest or token via `get_identity().verify_token`, then `status ready`; reject malformed with the error shape (1008) and oversized with 1009; 1,024-byte binary frames only; monotonic `sequence`; a heartbeat every 15 s; idle close at 90 s; a hard 600 s cap with a clean `ended`; a bounded number of connections per address and per user (configurable constant, default 4 and 2).
2. **Providers via ports only:** `ports.provider_adapters` for STT, TTS, Gemini. Build them from `get_settings()`/readiness. If a credential is missing, the call answers `status` then an `error` (`not_available`, plain words) and closes cleanly; it never half-starts. One STT session per connection with the VAD headers from `settings`; on a language change at a round boundary, reconnect STT carrying the same VAD object. Budget every wire attempt through the Phase 02 limits already inside the adapters; add a per-call ceiling constant.
3. **Turn controller** (`conversation/`): states connecting → listening → thinking → speaking → coaching. A turn is a conversational turn: join VAD segments until an end-of-turn policy fires (silence ≥ a configurable hold, default 1.2 s since the last segment, plus a minimum word count). It is **not** one segment. "Give me a moment" extends the hold. Four completed turns (the settings `coachingRoundTurns`) trigger a coaching break, announced at a natural boundary. The LLM never changes these rules. Reply text is untrusted: bound its length, strip control characters, never execute it. The prompt carries the scenario, level, practice and coaching language, and the transcript as quoted data.
4. **Interruption:** learner speech while the coach speaks → stop sending TTS, fence the turn (`TextToSpeechSession.cancel_consumption`), stop the Gemini wait, preserve round state, and respond; an acknowledgement does not count as a new round. A late reply or late audio from a fenced turn is never sent. Never say the provider cancelled. Keep an `interrupt`-to-last-audio-byte timing in the logs (numbers only).
5. **Analysis** (`analysis/`): re-home the Phase 02 measurement semantics (VAD speech regions, the four separated denominators, recognition status, the trusted-source rule) as a service module that satisfies `AnalysisPort`. Port code from `tools/probes/analysis/` into your tree; don't import it. Use the frozen method ids and denominators. The learner-only audio stream: coach audio never enters analysis. A missing transcript is `missing-transcription` and never 0. Fillers: always `insufficient_evidence` / `filler_detection_unvalidated`; no detector is shipped. The VAD model asset needs a sha256-checked, git-ignored cache folder inside your tree and an honest `unavailable` when it is absent. Never download silently at request time. Document the one-line prepare command.
6. **Round feedback and retry:** after the break trigger, build the `round_feedback` envelope from measured facts plus one Gemini call (structured, schema-checked, ≤1 strength, ≤2 improvements, 1 language note, in the coaching language, with `evidence[]` taken from the real metrics). Reject and degrade to a facts-only message if the model output fails validation. Coaching choices `Keep talking / Coach me now / Skip` and `retry` are handled; a retry reuses the same metric definitions on the same prompt. If a round has too little speech, say so and continue; no invented feedback.
7. **At call end:** compute the durable-metrics document (numbers and ids only, validated against the schema before use). Save through `get_session_store()` only per ADDENDUM §A. Metrics-only mode must leave no transcript, reply text, quoted text or custom topic in logs, caches, background tasks or exception messages. Logs carry ids, counts and durations only.
8. **Errors:** every failure category (auth, throttle, network, timeout, provider, internal) maps to the frozen error shape with a correct `retryable`.
