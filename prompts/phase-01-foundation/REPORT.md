## 6. Contract draft

Location: `packages/contracts/` (README there documents consumption rules).

| Schema | Purpose / key boundary |
|---|---|
| `catalog.schema.json` + `data/catalog.json` | Ten documented realtime languages + Hinglish as a separate code-mixed mode (`sttCode: en-IN`, `ttsCode: hi-en`); four capability states where only `documented` may be true; French cannot enter without a schema change. |
| `session-settings.schema.json` | Practice/coaching language, scenario, level, 1–8 turns per coaching round, 60–900s session cap (provider STT cap is 15 min), recording retention default off; consent is versioned and audio-only. |
| `event-envelope.schema.json` | Versioned, typed envelope with session/connection/round/turn ids, per-connection sequence, `sampleTimeMs` (audio clock) vs `emittedAt` (wall clock); binary audio travels out-of-band; base64 audio in JSON is rejected. |
| `analysis-observation.schema.json` | `measured` vs `inferred` source; `available`/`unavailable`/`insufficient_evidence`; value/unit nullability tied to status — zero is a real measurement, never a stand-in for "couldn't measure". |
| `durable-metrics.schema.json` | Allowlisted numeric results + method notes only; rejects `transcript`, `quotedMistakes`, `modelText`, `audioUrl`, `embedding` by name and everything else via closed objects. |
| `recording-metadata.schema.json` | Private opaque reference (no public/signed URL, no object key); owner as `usr_` id; versioned consent timestamp; lifecycle `retained`/`deleted` with required `deletedAt` when deleted. |
| `error-shape.schema.json` | Plain-word bounded message, stable category + code, correlation id; stack traces, raw provider payloads, raw transcripts and secrets rejected; client-error categories can never be `retryable`. |

- **Examples:** 36 fixtures (13 valid / 23 invalid) under `examples/<schema>/{valid,invalid}/`; the expectation comes from the folder name. `REQUIRED_FIXTURES` is asserted by **both** runtimes so neither can silently drop coverage. Fixture families cover: unavailable-vs-zero, null/empty units, invalid language codes (`fr-FR`), structurally-valid-but-unknown ids (`french` passes shape — membership is a runtime check), mismatched id prefixes, base64 audio smuggling, format violations (space-separated timestamps), negative sequences, and every forbidden durable field.
- **Two runtimes, same files:** Ajv (`Ajv2020`, strict, `allowUnionTypes`, ajv-formats) and Python (`Draft202012Validator` + `FormatChecker` with the `format-nongpl` extra). A paired fixture proves format checking is genuinely active in Python (the same document validates without the checker).
- **Transient vs durable difference:** observations/envelopes are ephemeral by design and carry evidence spans and text; the durable shape is numeric-only with method provenance. No schema permits copying transcript text into storage.
- **Open questions carried to Phase 03:** final envelope type set and per-type payload schemas; WS transport auth/origin/rate-limit design (OWASP WebSocket cheat sheet); how `sampleTimeMs` is derived in the browser reliably; metric-list freeze and disfluency algorithm choice; recording capture format (wav/pcm_s16le is a draft) and storage layout; consent wording versioning and default retention window; error-code taxonomy; stale-identifier fencing semantics (`connectionId` vs `sessionId`); whether additional format-behavior conformance fixtures are needed beyond date-time.

## 7. Known limits

- **Not implemented (by design):** live STT/TTS/LLM, WebSocket transport, audio analysis, accounts, storage, retention/deletion mechanics, deployment/CI. The service proves process readiness only.
- **No runtime language support is verified:** all ten languages (and Hinglish) are documentation-backed only; every capability flag except `documented` is `false`. No word-level timing exists or is synthesized.
- **npm audit:** 5 high findings in the dev-only lint chain (`braces` → `micromatch` → `fast-glob` → `@next/eslint-plugin-next` → `eslint-config-next`). npm's suggested fix is a breaking downgrade to eslint-config-next@14 — not taken. No production dependency is affected; revisit when Next ships a fixed glob chain.
- **eslint 9.39.5 deprecation warning** from npm: accepted trade-off until eslint-plugin-react/import/jsx-a11y support ESLint 10 (10.13.0 exists but conflicts with those peers).
- Headless Chromium cannot open native select popups, so select keyboard behavior is asserted as focusability + change handling (radios and checkbox keep full keyboard tests).
- e2e assertions that count controls are scoped to `<main>` because the Next dev-tools indicator renders its own portal outside the app tree in dev mode.
- `next build` rewrote two `tsconfig.json` values (standard Next 16 behavior; kept and documented).
- The sample preview is static text on purpose; no audio asset exists in the repo.
